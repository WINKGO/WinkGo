# PDF Toolkit provenance

`pdf-toolkit` was independently written as original WINK GO project material
on 2026-07-30. It replaces a previously removed PDF skill whose license did
not permit redistribution or derivative works.

No text, code, prompts, scripts, or assets from that removed skill were
copied into this directory. The workflow refers only to general PDF concepts
and the public command-line interfaces of tools such as Poppler, qpdf,
MuPDF, OCRmyPDF, and Tesseract. Those tools are not bundled by this skill and
remain subject to their own licenses when installed separately.
