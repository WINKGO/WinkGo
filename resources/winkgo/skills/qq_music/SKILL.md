# QQ 音乐

- Skill ID: `qq_music`
- Canonical hit name: `QQ音乐`
- Independent config scope: `qq_music`
- Runtime settings bridge: `music`

This package independently owns its card, configuration scope, routing metadata, and hit entry. Audited runtime tools may be reused underneath without exposing sibling skills in this package.

## Capability notes

- “我喜欢”用于打开或播放账号中已有的收藏，不代表支持给当前歌曲点喜欢或点红心。
- 音量能力调节 Windows 中 QQ 音乐进程的音频会话，不操作 QQ 音乐播放器底部的内部音量滑块。

## Not advertised / unsupported

- 喜欢当前歌曲
- 给当前歌曲点红心
