# 桌面 Computer Use

- Skill ID: `desktop_automation`
- Canonical hit name: `桌面 Computer Use`
- Independent config scope: `desktop_automation`
- Runtime settings bridge: `desktop_automation`

This package owns the visible desktop-control card and its stop action. Screen observation and verified actions are provided by the audited `desktop_automation` runtime plugin; pressing Esc or invoking `desktop_automation.cancel` must stop the current control session.
