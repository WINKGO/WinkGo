# WINK GO 网页技能录制器

## 目标

把用户在 WINK GO 应用内浏览器中完成的一次网页流程保存成可重复执行的本地技能。网页步骤由桌面端确定性回放，不把完整轨迹发送给 ESP32、移动端或云端，也不要求模型每次重新理解页面流程。

Agent 直接操作浏览器、统一动作协议和 ESP32 命令边界见 [WINK GO 浏览器控制中心](./winkgo-browser-control.md)。录制回放与直接控制共用同一个电脑端执行服务。

## 本地目录

技能按 WINK GO 账号隔离；未登录时使用本机 `local` 配置档：

```text
<userData>/winkgo-browser-skills/profiles/<profile-id>/
├── registry.json
└── skills/
    └── <skill-id>/
        ├── SKILL.md
        ├── manifest.json
        └── workflow.json
```

- `SKILL.md`：供技能中心和 Agent 理解用途、参数与安全要求。
- `manifest.json`：轻量元数据和 WINK GO runner 协议。
- `workflow.json`：仅由桌面端读取的确定性操作步骤。
- `registry.json`：只包含技能编号、名称、站点和参数名，供设备快速发现；不包含选择器、输入值或完整流程。

## 录制与回放

1. 用户在 WINK GO 浏览器中打开目标网页。
2. 在内置浏览器工具栏打开“网页技能录制”，点击开始。
3. 录制器捕获导航、点击、输入、选择和表单提交。
4. 用户填写技能名称并保存。
5. 展开已保存 Skill，可查看、排序或删除步骤并保存。
6. WINK GO 优先使用语义定位信息，必要时退回 CSS；原目标失效时仅对唯一语义匹配目标进行一次受控重试。

录制期间切换 WINK GO 浏览器标签页时，录制器会跟随当前受控标签页。回放严格串行执行，避免并行点击造成页面状态错乱。

## 隐私与安全

- 密码、验证码、Token、授权码、银行卡安全码等字段只保存为运行时参数，不保存原值。
- URL 中的用户名、密码和敏感查询参数会在落盘前删除。
- `data:`、`file:` 等非 HTTP(S) 导航不会录制或回放。
- 所有技能默认只在本机执行。
- 保存使用临时目录和原子重命名，避免产生不完整技能包。
- 删除仅允许发生在当前账号的网页技能根目录内。

## ESP32 精简调用协议

设备侧后续只需要发送：

```json
{
  "command": "browser.skill.run",
  "skill_id": "daily-report-abc123",
  "parameters": {
    "input_1": "2026-08-08"
  }
}
```

桌面端根据 `skill_id` 读取私有 `workflow.json` 并执行。设备不接收完整步骤，因此可以显著减少传输量和模型上下文消耗。当前桌面版已经生成这份精简注册表；ESP32/Runtime 的远端调度入口应在协议联调阶段接入，不需要改动现有技能文件格式。

## 实现边界

当前实现是 WINK GO 原生的干净实现，复用现有应用内浏览器、CDP 安全桥和 IPC 架构，不捆绑第三方浏览器录制项目、扩展、服务端接口或品牌资源。
