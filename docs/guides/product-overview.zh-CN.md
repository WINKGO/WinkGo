# WINK GO · AI 智能体工作台

本文档说明 WINK GO 2.1.45 的产品入口、当前能力、使用条件和后续路线图。

## 状态说明

| 标记     | 含义                                                   |
| -------- | ------------------------------------------------------ |
| 已上线   | 当前代码和产品入口均已具备                             |
| 条件可用 | 功能已经实现，但需要系统能力、外部运行时、凭据或网络   |
| 实验性   | 已有产品入口或桥接代码，但公开仓库尚不包含完整运行资产 |
| 规划中   | 当前尚未实现，仅代表后续方向                           |

当前发布阶段，免费版通过统一能力策略获得全部 Pro 能力。Pro 只保留为未来版本与授权边界。

## 产品入口地图

### 首页与 AI 对话

**状态：已上线**

- 新建任务、选择助手、选择智能体和选择模型。
- 流式文本、思考过程、计划、工具调用和执行状态展示。
- 工具权限确认、停止生成、失败恢复和会话继续。
- 会话历史搜索、分组、重命名、删除和导出。
- 引用工作区文件、拖入文件、粘贴内容和图片输出。
- 麦克风录音与音频文件转文字。

语音输入需要麦克风权限及 STT 服务配置。OpenAI 兼容端点可用于整段转写，支持流式协议的端点可以提供增量结果，Deepgram 也可作为实时转写服务。

### 工作区与文件

**状态：已上线**

- 浏览、上传、拖入、读取、新建、复制、重命名、删除、压缩和搜索文件。
- 监听文件变化，并同步刷新对话工作区。
- 查看快照、Diff、暂存、取消暂存和丢弃变更。
- 浏览 Git 分支和工作区状态。
- 预览图片、Markdown、HTML、PDF、URL、Diff、Word、Excel 和 PowerPoint。
- 对 Office 文件进行实时变化监听。

WINK GO 提供文件工作流、内容预览和转换，不等同于原生 Word、Excel 或 PowerPoint 编辑器。

### 智能体管理

**状态：已上线**

- WINK GO CLI 智能体。
- 托管的 Claude CLI 与 Codex CLI 接入。
- 自定义 ACP 兼容智能体。
- 本机检测、健康检查、修复、启停和删除。
- 自定义命令、参数、环境变量、头像和高级 ACP 配置。
- 按会话切换模型、运行模式和工作目录。

外部 CLI 是否可用取决于本机安装、账号登录和相应服务状态。仓库中的 Skills 或适配目录不代表同名品牌已经作为聊天智能体接入。

### 助手

**状态：已上线**

- 创建和管理不同身份的助手。
- 设置系统提示词、上下文、规则与欢迎信息。
- 绑定默认智能体、模型、权限策略和工作区。
- 绑定多个 Skills，形成可复用的工作角色。

### 多智能体团队

**状态：已上线**

- 创建团队、设置团队目标并配置多个角色。
- 为成员分配智能体、模型、职责和共享工作区。
- 支持团队群发、成员私聊、任务交接和队列消息。
- 查看成员运行、等待、暂停、失败和完成状态。
- 对任务执行取消、暂停、唤醒和重试。

### MCP 工具

**状态：已上线 / 条件可用**

- 新增、编辑、删除、启停和测试 MCP 服务。
- JSON 导入、批量导入和工具目录查看。
- 支持 stdio、Streamable HTTP 和兼容旧版 SSE 的服务。
- 支持远程 MCP OAuth 流程。
- 在智能体运行时动态发现并调用 MCP 工具。

外部 MCP 服务可能依赖 Node.js、Python、系统二进制、OAuth、API Key 或网络连接。

### Skills 中心

**状态：已上线**

- 扫描本地 Skills。
- 从文件夹或 ZIP 导入。
- 启停、删除、批量管理和查看导入历史。
- 查看 Skill 详情，并把 Skill 绑定到指定助手。
- 加载随包提供的只读 Skills。

部分 Skill 只是工作流或动作说明，需要对应工具、应用或账号才能完成实际操作。

### 定时任务

**状态：已上线**

- 创建、编辑、删除、启停和立即执行。
- 支持每小时、每日、工作日、每周和自定义 Cron。
- 指定助手、智能体、模型、工作区和提示词。
- 设置失败重试和无人值守运行。
- 查看运行历史、输出和关联会话。

### 格式工坊

**状态：已上线 / 条件可用**

内置文本工具：

- 文本清洗。
- JSON 格式化。
- Markdown 大纲整理。

内置文件转换：

- NCM 转 MP3。
- 视频转 MP4。
- 视频压缩。
- GIF 压缩。
- FLAC、WAV、M4A 等音频转 MP3。
- 图片压缩并输出 JPG。
- Office/OpenDocument 转 PDF。

音视频、GIF 和部分 NCM 转换依赖 FFmpeg；文档转 PDF 依赖 WPS Office 或 LibreOffice。页面会先检测本机引擎再开放对应操作。

### 灵感中心

**状态：已上线 / 条件可用**

- 提供六个本地生活任务模板。
- 提供滴滴 MCP、高德 Web API 和美团本地适配器的配置、连通测试与预览。
- 可把模板转换为新任务并交给智能体继续处理。

这些入口不代表 WINK GO 可以绕过用户确认直接下单、支付或导航。服务能力取决于官方凭据、网络和本地适配器。麦当劳、瑞幸等目录项仍在等待实际端点接入。

### AI 知识画布

**状态：实验性**

- 已有独立页面、AI 分析桥接、来源信息和可编辑画布数据结构。
- 可以选择在线智能体执行后台研究与结构化分析。

公开仓库没有包含被隔离的第三方画布运行资产，干净克隆无法直接得到完整画布页面。该能力会在运行资产来源、许可和交付方式确认后继续完善。

### WebUI

**状态：已上线 / 条件可用**

- 从桌面设置启停 WebUI。
- 默认端口 `25808`。
- 局域网访问、Windows 防火墙授权和二维码令牌。
- 管理员密码与登录会话。
- CLI/无界面启动。
- 静态页面托管，以及 `/api`、WebSocket 和 STT 流的代理。

局域网访问应只在可信网络中使用。公网部署需要自行配置 HTTPS、访问控制、反向代理、安全组或安全隧道。

### 消息渠道

**状态：部分上线**

当前后端已经实现：

- Telegram。
- 飞书/Lark。
- 钉钉。
- 微信。

企业微信、Slack 和 Discord 当前仍是待适配状态。所有渠道都需要对应平台的机器人、应用、令牌或回调配置。

### 小智与远程设备

**状态：条件可用**

- 探测并启停本机 Runtime 或 LAN Bridge。
- 配置硬件端点和移动端连接。
- 文字或语音命令入口。
- 工作区隧道与灵动岛连接状态。
- 可选云端中继和小程序绑定。

该能力依赖本机桥接程序、设备端配置、账号、密钥、网络和可用的云服务。

### 桌面宠物、主题与系统设置

**状态：已上线**

- 桌面宠物显示、状态和交互设置。
- 浅色/深色主题、界面外观和自定义主题。
- 系统托盘、通知、快捷键、启动与更新设置。
- 扩展设置页和运行时诊断。

## 灵动岛完整说明

### 桌面形态

- 嵌入主窗口标题栏。
- 独立透明置顶浮窗。
- 自动伸缩、拖动定位和跨工作区显示。
- 设置可见性、透明度、主题和全屏自动隐藏。
- 通过全局快捷键打开文件收纳。

Windows 还提供原生 OLE 文件拖入，用于接收普通路径和微信等应用产生的虚拟文件。

### AI 与工具状态

- 显示当前智能体身份和运行状态。
- 展示工具/MCP 调用、完成、失败与待授权提醒。
- 以摘要和滚动文本呈现最近活动。
- 对活动文本过滤 Token、Password、API Key 等敏感标记及本地绝对路径。

### 系统媒体与通知

- 读取 Windows 系统媒体会话。
- 显示曲目信息、来源和封面。
- 上一首、播放/暂停、下一首。
- 汇总 Windows 通知并以卡片展示。
- 通知隐私模式。

### 专注与定时任务

- 1–180 分钟专注计时。
- 开始、暂停、继续和结束。
- 展示下一项定时任务和当前运行摘要。
- 快速跳转到定时任务页面。

### 文件收纳

- 拖放接收与批量暂存。
- 自动分类和智能重命名。
- 自定义分类、收纳规则和目标目录。
- 复制或移动文件。
- 批次撤销。
- 最近文件架和文件夹跳转。

### 快速格式转换

- NCM 转 MP3。
- 视频转 MP4 或压缩。
- GIF 压缩。
- 音频转 MP3。
- 图片压缩。
- 文档转 PDF。
- 查看进度、成功、失败和输出目录。

## 技术架构

```text
React Renderer
  ├─ 对话 / 工作区 / 灵动岛 / 设置
  ├─ Preload IPC：受控调用桌面与操作系统能力
  └─ HTTP / WebSocket Adapter
          ↓
Axum + Tokio / winkgo_core
  ├─ Auth / Conversation / Files / Office
  ├─ Agent Runtime / ACP / MCP / Skills
  ├─ Teams / Cron / Channels / Extensions
  └─ SQLite / 本地文件 / 外部服务
```

技术基础：

- Electron 37.10.3。
- React 19.1、TypeScript 5.8、Vite 6.4。
- Rust 2024 edition、Tokio、Axum。
- SQLite、SQLx 与 WAL。
- ACP 智能体协议。
- MCP stdio、Streamable HTTP、兼容 SSE 与 OAuth。
- REST + WebSocket 实时事件。
- Vitest、Playwright 与 Rust 测试体系。
- Windows、macOS、Linux 的 x64/ARM64 构建流水线。

## 后续路线图

### 1. 扩充灵动岛日常工具集合

围绕剪贴板、提醒、快捷动作、系统状态和高频桌面操作继续扩充灵动岛。

### 2. 灵动岛语音识别与控制

将当前聊天语音转文字能力延伸至灵动岛，加入语音指令、唤起和桌面动作路由。

### 3. 灵动岛统一 AI 入口

把 AI 对话、上下文、工具调用和当前工作区接入灵动岛，形成随时可用的轻量智能入口。

### 4. 速度与性能持续优化

继续优化冷启动、首屏渲染、后台资源占用、智能体调度、MCP 连接和大文件处理。

### 5. 持续接入更多智能体

优先扩展 ACP 与自定义智能体兼容，并继续建设 MCP、Skills、设备和消息渠道生态。

路线图仅表示方向，具体交付范围和版本日期以正式 Release 为准。
