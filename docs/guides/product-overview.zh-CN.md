# WINK GO · AI 智能体工作台

本文档说明 WINK GO 当前公开版本的产品入口、当前能力、使用条件和后续路线图。

## 状态说明

| 标记     | 含义                                                   |
| -------- | ------------------------------------------------------ |
| 已上线   | 当前代码和产品入口均已具备                             |
| 条件可用 | 功能已经实现，但需要系统能力、外部运行时、凭据或网络   |
| 实验性   | 已有产品入口或桥接代码，但公开仓库尚不包含完整运行资产 |
| 规划中   | 当前尚未实现，仅代表后续方向                           |

WINK GO 当前作为开放、免费、公益性质的项目发布，桌面客户端现有功能全部开放，不设置付费功能分级。第三方模型、API、云端中转、语音和消息平台等外部资源可能由相应服务方计费。

## 产品入口地图

### 首页与 AI 对话

**状态：已上线**

- 新建任务、选择助手、选择智能体和选择模型。
- 流式文本、思考过程、计划、工具调用和执行状态展示。
- 工具权限确认、停止生成、失败恢复和会话继续。
- 会话历史搜索、分组、重命名、删除和导出。
- 引用工作区文件、拖入文件、粘贴内容和图片输出。
- 麦克风录音与音频文件转文字。

语音输入需要麦克风权限及 STT 服务配置。OpenAI 兼容端点可用于整段转写，支持流式协议的端点可以提供增量结果，Deepgram 也可作为实时转写服务。

### 工作区与文件

**状态：已上线**

- 浏览、上传、拖入、读取、新建、复制、重命名、删除、压缩和搜索文件。
- 监听文件变化，并同步刷新对话工作区。
- 查看快照、Diff、暂存、取消暂存和丢弃变更。
- 浏览 Git 分支和工作区状态。
- 预览图片、Markdown、HTML、PDF、URL、Diff、Word、Excel 和 PowerPoint。
- 对 Office 文件进行实时变化监听。

WINK GO 提供文件工作流、内容预览和转换，不等同于原生 Word、Excel 或 PowerPoint 编辑器。

### 智能体管理

**状态：已上线**

- WINK GO CLI 智能体。
- 用户自行安装的 Anthropic 官方 Claude Code CLI 与 OpenAI 官方 Codex CLI 接入。
- 自定义 ACP 兼容智能体。
- 本机检测、健康检查、修复、启停和删除。
- 自定义命令、参数、环境变量、头像和高级 ACP 配置。

Claude Code 与 Codex 都不属于 WINK GO 发布包：应用不会下载或再分发
它们的二进制及 sidecar，只检测用户自行安装并加入 `PATH` 的官方
`claude`/`codex` 命令。用户需自行遵守 Anthropic/OpenAI 的官方条款。

启动 Claude 会话前必须显式配置 `ANTHROPIC_API_KEY`，或同时配置兼容网关
的 `ANTHROPIC_AUTH_TOKEN` 与 `ANTHROPIC_BASE_URL`。WINK GO 不复用
Claude.ai 免费版、Pro 或 Max 订阅 OAuth。

- 按会话切换模型、运行模式和工作目录。

外部 CLI 是否可用取决于本机安装、账号登录和相应服务状态。仓库中的 Skills 或适配目录不代表同名品牌已经作为聊天智能体接入。

### 助手

**状态：已上线**

- 创建和管理不同身份的助手。
- 设置系统提示词、上下文、规则与欢迎信息。
- 绑定默认智能体、模型、权限策略和工作区。
- 绑定多个 Skills，形成可复用的工作角色。

### 多智能体团队

**状态：已上线**

- 创建团队、设置团队目标并配置多个角色。
- 为成员分配智能体、模型、职责和共享工作区。
- 支持团队群发、成员私聊、任务交接和队列消息。
- 查看成员运行、等待、暂停、失败和完成状态。
- 对任务执行取消、暂停、唤醒和重试。

### MCP 工具

**状态：已上线 / 条件可用**

- 新增、编辑、删除、启停和测试 MCP 服务。
- JSON 导入、批量导入和工具目录查看。
- 支持 stdio、Streamable HTTP 和兼容旧版 SSE 的服务。
- 支持远程 MCP OAuth 流程。
- 在智能体运行时动态发现并调用 MCP 工具。

外部 MCP 服务可能依赖 Node.js、Python、系统二进制、OAuth、API Key 或网络连接。

### Skills 中心

**状态：已上线**

- 扫描本地 Skills。
- 从文件夹或 ZIP 导入。
- 启停、删除、批量管理和查看导入历史。
- 查看 Skill 详情，并把 Skill 绑定到指定助手。
- 加载随包提供的只读 Skills。

部分 Skill 只是工作流或动作说明，需要对应工具、应用或账号才能完成实际操作。

### 定时任务

**状态：已上线**

- 创建、编辑、删除、启停和立即执行。
- 支持每小时、每日、工作日、每周和自定义 Cron。
- 指定助手、智能体、模型、工作区和提示词。
- 设置失败重试和无人值守运行。
- 查看运行历史、输出和关联会话。

### 格式工坊

**状态：已上线 / 条件可用**

内置文本工具：

- 文本清洗。
- JSON 格式化。
- Markdown 大纲整理。

内置文件转换：

- NCM 转 MP3。
- 视频转 MP4。
- 视频压缩。
- GIF 压缩。
- FLAC、WAV、M4A 等音频转 MP3。
- 图片压缩并输出 JPG。
- Office/OpenDocument 转 PDF。

音视频、GIF 和部分 NCM 转换依赖 FFmpeg；文档转 PDF 依赖 WPS Office 或 LibreOffice。页面会先检测本机引擎再开放对应操作。

### 灵感中心

**状态：已上线 / 条件可用**

- 提供六个本地生活任务模板。
- 提供滴滴 MCP、高德 Web API 和美团本地适配器的配置、连通测试与预览；美团官方 Skill 由用户从授权来源自行取得并选择本地目录，公开安装包不代为捆绑。
- 可把模板转换为新任务并交给智能体继续处理。

这些入口不代表 WINK GO 可以绕过用户确认直接下单、支付或导航。服务能力取决于官方凭据、网络和本地适配器。麦当劳、瑞幸等目录项仍在等待实际端点接入。

### AI 知识画布

**状态：实验性**

- 已有独立实验入口、AI 分析桥接和结构化分析数据模型。
- 公开版本会明确提示该能力仍处于实验阶段，不加载未审核的运行组件。

公开仓库和安装包不包含尚未完成来源、许可与发布材料审核的完整画布运行组件。完成权属链、可复现构建、第三方许可证与发布测试后，才会考虑开放该能力。

### WebUI

**状态：已上线 / 条件可用**

- 从桌面设置启停 WebUI。
- 默认端口 `25808`。
- 局域网访问、Windows 防火墙授权和二维码令牌。
- 管理员密码与登录会话。
- CLI/无界面启动。
- 静态页面托管，以及 `/api`、WebSocket 和 STT 流的代理。

局域网访问应只在可信网络中使用。公网部署需要自行配置 HTTPS、访问控制、反向代理、安全组或安全隧道。

### 消息渠道

**状态：部分上线**

当前后端已经实现：

- Telegram。
- 飞书/Lark。
- 钉钉。
- 微信。

企业微信、Slack 和 Discord 当前仍是待适配状态。所有渠道都需要对应平台的机器人、应用、令牌或回调配置。

### 小智与远程设备

**状态：条件可用**

- 探测并启停本机 Runtime 或 LAN Bridge。
- 使用 10 位一次性设备码把配套小程序与指定电脑绑定。
- 在小程序查看电脑绑定与在线状态，并进入已绑定电脑的远程 WebUI。
- 使用独立的账号、安装实例、电脑、Agent、会话和任务标识进行隔离。
- 展示工作区隧道、云端中转、ESP32 和灵动岛连接状态。

首次配对：

1. 在桌面端登录 WINK GO。
2. 进入 **设置 → MCP 配置 → 小智 MCP 连接**。
3. **云端设备转发** 默认开启；执行 **检测并修复**。若不使用远程设备能力，可随时关闭。
4. 在 **手机小程序设备绑定** 区域查看 10 位一次性设备码。
5. 在配套小程序的绑定页输入该码并确认。
6. 绑定完成后，在小程序查看电脑状态，并通过 **远程 WebUI** 进入已绑定电脑。

设备码有效期为 5 分钟且只能使用一次，过期后可在桌面端重新获取。桌面链路还会执行账号归属、时间戳、随机数、任务身份和重复投递校验。云端只负责登录鉴权、绑定、消息路由和结果转发，不替用户运行完整桌面 Agent。

当前小程序没有对外开放原生聊天或语音任务页面；Relay 协议具备消息转发能力，不等于相应小程序界面已经上线。该能力依赖本机 Runtime、账号、网络和可用的云端中转。项目源码与桌面功能免费开放，但云端中转、语音服务、模型和其他外部资源可能产生费用，具体以对应服务说明为准。

局域网 WebUI / 移动端采用另一套二维码令牌流程，不使用上述 10 位码：桌面端启动 WebUI 后，手机与电脑接入同一可信局域网，再扫描桌面端显示的二维码。局域网访问可能需要放行防火墙，不应把没有 HTTPS 和访问控制的本地端口直接暴露到公网。

- 开始、暂停、继续和结束。

### 文件收纳

### 快速格式转换

- 视频转 MP4 或压缩。
- GIF 压缩。
- 音频转 MP3。
- 图片压缩。
- 文档转 PDF。
- 查看进度、成功、失败和输出目录。

## 技术架构

```text
React Renderer
  ├─ 对话 / 工作区 / 灵动岛 / 设置
  ├─ Preload IPC：受控调用桌面与操作系统能力
  └─ HTTP / WebSocket Adapter
          ↓
Axum + Tokio / winkgo_core
  ├─ Auth / Conversation / Files / Office
  ├─ Agent Runtime / ACP / MCP / Skills
  ├─ Teams / Cron / Channels / Extensions
  └─ SQLite / 本地文件 / 外部服务
```

技术基础：

- Electron 41.10.3。
- React 19.2、TypeScript 5.8、Vite 6.4。
- Rust 2024 edition、Tokio、Axum。
- SQLite、SQLx 与 WAL。
- ACP 智能体协议。
- MCP stdio、Streamable HTTP、兼容 SSE 与 OAuth。
- REST + WebSocket 实时事件。
- Vitest、Playwright 与 Rust 测试体系。
- Windows、macOS、Linux 的 x64/ARM64 构建流水线。

## 后续路线图

### 1. 扩充灵动岛日常工具集合

围绕剪贴板、提醒、快捷动作、系统状态和高频桌面操作继续扩充灵动岛。

### 2. 灵动岛语音识别与控制

将当前聊天语音转文字能力延伸至灵动岛，加入语音指令、唤起和桌面动作路由。

### 3. 灵动岛统一 AI 入口

把 AI 对话、上下文、工具调用和当前工作区接入灵动岛，形成随时可用的轻量智能入口。

### 4. 速度与性能持续优化

继续优化冷启动、首屏渲染、后台资源占用、智能体调度、MCP 连接和大文件处理。

### 5. 持续接入更多智能体

优先扩展 ACP 与自定义智能体兼容，并继续建设 MCP、Skills、设备和消息渠道生态。

路线图仅表示方向，具体交付范围和版本日期以正式 Release 为准。
