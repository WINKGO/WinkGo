# Snow Agent 安装状态

WINK GO 仍保留 Snow 的历史 ACP 配置（命令：`snow --acp`），用于兼容已有数据库和会话。

截至 2026-07-31，Snow 不在官方 [ACP Registry](https://github.com/agentclientprotocol/registry) 中，项目也无法确认仍有效的官方安装来源。因此本项目不会提供一个未经核实的下载地址，也不会自动安装同名 npm 包。

如果你已有可信来源安装的 Snow CLI，可在终端确认 `snow --acp` 可运行，然后回到 WINK GO 的 Agents 页面测试连接。新用户应选择列表中具有官方安装来源的 Agent。
