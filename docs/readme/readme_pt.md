# WINK GO

WINK GO é um espaço de trabalho desktop multiplataforma para agentes de IA, reunindo agentes, arquivos, ferramentas, habilidades, tarefas agendadas, WebUI e colaboração multiagente.

- **Free 2.1.45: acesso completo.** Atualmente inclui todos os recursos disponíveis na compilação Pro.
- **Pro: reservado para o futuro.** No momento, não desbloqueia recursos adicionais.
