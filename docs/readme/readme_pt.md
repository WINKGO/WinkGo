# WINK GO

WINK GO é um espaço de trabalho desktop multiplataforma para agentes de IA, reunindo agentes, arquivos, ferramentas, habilidades, tarefas agendadas, WebUI e colaboração multiagente.

## Projeto aberto e gratuito

Todos os recursos atuais do cliente desktop estão disponíveis para todos. Modelos, APIs, retransmissão em nuvem, voz e outros serviços externos podem ter custos próprios.
