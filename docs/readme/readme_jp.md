# WINK GO

WINK GO は、エージェント、ファイル、ツール、スキル、スケジュール、WebUI、マルチエージェント連携を一つにまとめるクロスプラットフォームの AI Agent デスクトップワークスペースです。

## エディション

- **Free 2.1.45：全機能を利用可能。** 現在の Pro ビルドに含まれる機能もすべて利用できます。
- **Pro：将来向けに予約。** 現時点で追加機能の解除はありません。
