# WINK GO

WINK GO は、エージェント、ファイル、ツール、スキル、スケジュール、WebUI、マルチエージェント連携を一つにまとめるクロスプラットフォームの AI Agent デスクトップワークスペースです。

## オープンで無料のプロジェクト

デスクトップクライアントの現在の機能は、すべてのユーザーに開放されています。外部のモデル、API、クラウド中継、音声サービスなどには、各サービスの利用料金が発生する場合があります。
