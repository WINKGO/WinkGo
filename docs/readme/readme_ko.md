# WINK GO

WINK GO는 에이전트, 파일, 도구, 스킬, 예약 작업, WebUI 및 다중 에이전트 협업을 하나로 통합한 크로스 플랫폼 AI Agent 데스크톱 작업 공간입니다.

## 에디션

- **Free 2.1.45: 전체 기능 제공.** 현재 Pro 빌드에 포함된 모든 기능을 사용할 수 있습니다.
- **Pro: 향후 버전을 위해 예약됨.** 현재 추가 기능을 잠금 해제하지 않습니다.
