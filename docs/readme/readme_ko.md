# WINK GO

WINK GO는 에이전트, 파일, 도구, 스킬, 예약 작업, WebUI 및 다중 에이전트 협업을 하나로 통합한 크로스 플랫폼 AI Agent 데스크톱 작업 공간입니다.

## 개방형 무료 프로젝트

현재 데스크톱 클라이언트의 모든 기능은 모든 사용자에게 열려 있습니다. 외부 모델, API, 클라우드 릴레이, 음성 및 기타 서비스에는 해당 제공자의 비용이 발생할 수 있습니다.
