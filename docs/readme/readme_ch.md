# WINK GO · AI 智能体工作台

WINK GO 是一个本地优先、跨平台的 AI 智能体工作台，统一管理智能体、模型、Skills、MCP、本地文件、自动化、WebUI 与桌面灵动岛。

WINK GO 当前作为开放、免费、公益性质的项目发布，桌面客户端现有功能向所有用户开放。第三方模型、API、云端中转、语音或其他外部服务可能产生费用。
