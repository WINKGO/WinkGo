# WINK GO

WINK GO 是一款跨平台 AI Agent 桌面工作空间，统一提供 Agent、文件、工具、技能、定时任务、WebUI 与多 Agent 协作能力。

## 版本状态

- **免费版 2.1.45：完整开放。** 当前可使用现有 Pro 构建中的全部功能。
- **Pro：预留版本。** 目前不额外解锁功能，后续用于独立版本与授权规划。
