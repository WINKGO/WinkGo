# WINK GO

WINK GO 是跨平台 AI Agent 桌面工作空間，統一提供 Agent、檔案、工具、技能、排程任務、WebUI 與多 Agent 協作能力。

## 版本狀態

- **免費版 2.1.45：完整開放。** 目前可使用現有 Pro 建置中的全部功能。
- **Pro：預留版本。** 目前不額外解鎖功能，後續用於獨立版本與授權規劃。
